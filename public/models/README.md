# Models

Low-poly glTF models served as static assets (not bundled into JS).

| File                  | Used for       | Source                                                     | License          |
| --------------------- | -------------- | ---------------------------------------------------------- | ---------------- |
| `foundry_<class>.glb` | ships, carrier | Generated by `scripts/blender/build_fleet.py` (this repo)  | MIT, as the repo |
| `meteor.glb`          | near asteroids | [Kenney Space Kit 2.0](https://kenney.nl/assets/space-kit) | CC0 1.0          |

The Foundry ships are built procedurally in Blender. To change one, edit
`scripts/blender/foundry.py` and regenerate every file:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup \
  -P scripts/blender/build_fleet.py -- public/models
```

Materials keep the slot names `src/render/models.ts` reads: `metalRed` is the accent the game
recolours per class, and the carrier draws `glow` unlit so bloom picks it up.

`meteor.glb` is an unmodified copy from `Models/GLTF format/` of `kenney_space-kit.zip`
(downloaded from kenney.nl). The kit's license text is in `kenney-space-kit-LICENSE.txt`.
